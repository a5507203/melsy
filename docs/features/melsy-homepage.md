# Melsy 官网首页 MVP

## Concept Brief

当前阶段：实现前的需求验证与方案设计。

目标用户：潜在客户、政府与园区低空业务方、合作高校和企业、投资/媒体访客。

核心问题：项目已经有官网架构图和大量素材，但当前可运行页面仍是旧版单页，不能完整呈现 Melsy 的“物理 AI / 具身空间智能 / 低空任务”定位。

核心概念：
- Melsy 官网：首页式品牌和产品入口，不是后台系统或 CMS。
- 一脑多体软硬一体系统：空间训练场、COS、碎蜂共同支撑低空真实任务。
- 产品与方案：碎蜂、COS、空间训练场三个可被业务访客理解的产品单元。
- 研究与技术：合作网络、论文成果和人才梯队，用于建立可信度。

MVP 边界：重做中文静态首页，覆盖 Hero、近期合作、Section3 核心系统、Section4 场景验证、产品与方案、关于墨悉、研究与技术、联系入口；旧版放入 `stale/old-homepage/` 可回滚。

非目标：不做 CMS、后台管理、表单提交、多页面详情、完整英文站和在线购买流程。

关键假设：现有 `墨悉官网/` 目录是素材库；`官网设计架构.png` 是信息架构来源；第一版可用静态 HTML/CSS/JS 承载。

待确认问题：中英文站、产品详情页、外部链接和正式联系方式后续再确认。

## Acceptance Scenarios

- Given 用户打开首页，When 首屏加载，Then 能看到 Melsy 品牌、主张“感知空间 协同智能”和具身空间智能定位。
- Given 用户向下浏览，When 到达核心系统区域，Then 能理解空间训练场、COS、碎蜂之间的关系。
- Given 用户寻找业务场景，When 浏览场景验证区域，Then 能看到低空安全、低空经济、具身空间智能三类场景。
- Given 用户评估可信度，When 浏览关于墨悉和研究与技术，Then 能看到公司介绍、动态、合作机构、论文和人才梯队信息。
- Given 维护者需要回滚，When 查看 `stale/old-homepage/`，Then 能找到旧版 `index.html` 和 `logo.png`。

## Test Plan

- Static smoke test: 检查首页必需栏目、核心文案和本地素材引用。
- Browser verification: 用本地 HTTP 服务检查桌面和移动端截图，确认图片/视频加载和布局不破版。
- Manual verification: 核对旧版已归档，新素材目录没有被移动到 `stale`。
